# Irfan Akram Portfolio

Personal portfolio site built with Next.js, React, TypeScript, and Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

- `npm run dev` - start the development server
- `npm run build` - build the static site to `out/`
- `npm start` - serve the production build on port 3000
- `npm run lint` - run ESLint
- `npm run typecheck` - run TypeScript checks
- `npm run test:e2e` - run Playwright tests

## Content

Portfolio content lives in `src/data/portfolio.ts`.

Static assets live in `public/`.

## Deployment

The project uses Next.js static export and can be deployed from the generated `out/` directory.
